# CS497_Capstone

# SynPros Website Modernization Project (Leveraging AI for small business automation)

## Overview
This project focused on improving the SynPros website and customer booking workflow. The goal was to create a more user-friendly experience for customers while reducing scheduling conflicts and administrative effort for the business owner.

The updated website is currently deployed and accessible online.

## View the Updated Website

Please visit:

👉 https://synpros.biz/homev2

The updated website includes:
- Improved layout and navigation
- Enhanced service information
- Updated booking workflow
- Better customer intake process
- Mobile-friendly design improvements
- Integration with YouCanBook.Me for appointment scheduling

## Source Code

The primary HTML file used for this project has been uploaded to this repository, as it contains the majority of the website changes and enhancements completed during the Capstone project.

Additional website assets and production files may exist on the live server. To review the complete implementation:

1. Navigate to https://synpros.biz/homev2
2. Right-click anywhere on the page
3. Select **Inspect** or **View Page Source**
4. Review the HTML, CSS, JavaScript, and other front-end assets used by the site

## Project Objectives

- Improve website usability and customer experience
- Reduce appointment scheduling conflicts
- Collect more detailed project information before appointments
- Streamline communication between customers and the business owner
- Leverage existing business systems instead of replacing them
